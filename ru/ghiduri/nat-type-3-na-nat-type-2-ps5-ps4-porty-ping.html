1. Чем отличаются NAT Type 1, 2 и 3 (почему нужен именно NAT Type 2)

NAT Type 1 означает прямое подключение без роутера. NAT Type 2 — оптимальный и безопасный стандарт при работе через домашний роутер: открыт голосовой чат, стабильный подбор матчей и сохраняется защита сети. NAT Type 3 (строгий) блокирует входящие порты и мешает совместной игре.

2. Статический IP консоли, UPnP и точные порты PSN / CoD / EA FC

Узнайте IPv4 и MAC-адрес консоли в Настройки → Сеть → Статус соединения. В настройках роутера закрепите за консолью статический IP (DHCP Reservation) и включите UPnP. Если NAT Type 3 остался, настройте проброс портов (Port Forwarding) на IP консоли: TCP 80, 443, 3478, 3479, 3480, 1935 и UDP 3478, 3479, 3074. После сохранения полностью перезагрузите роутер и консоль.

3. Если порты не помогли: Double NAT и серый IP (CGNAT) у провайдера

Если ваш Wi-Fi роутер подключён за оптическим терминалом провайдера, возникает Double NAT — переведите терминал в режим моста (Bridge Mode). Если же провайдер выдаёт «серый» IP за CGNAT, никакие настройки роутера не откроют порты: нужно запросить у провайдера выделенный белый IPv4. Для минимального пинга и отсутствия потери пакетов подключайте PS5/PS4 кабелем Ethernet напрямую к роутеру.

Частые вопросы

Обязательно ли добиваться NAT Type 1 на PS5?

Нет. NAT Type 2 обеспечивает полную совместимость с голосовым чатом и серверами онлайн-игр, при этом консоль остаётся за базовой защитой домашнего роутера.

Помогает ли кабель LAN вместо Wi-Fi в EA FC и Call of Duty?

Да — кабель Ethernet убирает помехи соседних Wi-Fi сетей, снижает джиттер и потерю пакетов гораздо сильнее, чем увеличение тарифа скорости интернета.
