1. Подключение по кабелю USB-C vs Bluetooth (Create + PS)

По кабелю USB-C геймпад определяется в Windows 11 мгновенно и раскрывает полный Haptic Feedback и адаптивные триггеры в поддерживаемых играх. Для Bluetooth выключите геймпад, зажмите одновременно кнопки Create + PS до быстрого мигания подсветки, затем добавьте «Wireless Controller» в Параметрах Windows 11 → Bluetooth.

2. Настройка в Steam и для игр вне Steam

В Steam включите поддержку контроллеров PlayStation (Настройки → Контроллер). В играх с нативной поддержкой DualSense (Spider-Man, Cyberpunk 2077, Returnal) лучше отключить Steam Input в свойствах конкретной игры и подключиться по USB. Для Epic Games / GOG можно использовать DS4Windows или DualSenseX.

Частые вопросы

Работает ли полная тактильная отдача DualSense по Bluetooth на Windows?

В большинстве игр на Windows полный Haptic Feedback требует проводного подключения по USB-C; по Bluetooth работает стандартная вибрация и в отдельных играх — адаптивные триггеры.
