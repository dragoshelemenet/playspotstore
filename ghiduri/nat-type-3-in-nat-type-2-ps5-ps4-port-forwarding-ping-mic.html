1. Ce înseamnă NAT Type 1, 2 și 3 pe PlayStation (și de ce NAT Type 2 este ideal)

NAT Type 1 apare doar când consola este conectată direct la internet fără router (rar și mai puțin protejat). NAT Type 2 este setarea ideală și sigură pentru orice router de acasă: consola comunică liber cu serverele PlayStation Network și cu prietenii. NAT Type 3 (Strict) blochează porturile de intrare și provoacă erori de party chat, deconectări în Ultimate Team și timpi lungi de matchmaking.

2. IP static pentru PS5/PS4, DNS curat și activarea UPnP în router

Deschide pe consolă Settings → Network → Connection Status → View Connection Status și notează adresa IPv4 și adresa MAC a consolei. Intră în panoul routerului (de obicei 192.168.0.1 sau 192.168.1.1), atribuie un IP static (DHCP Reservation) pentru adresa MAC a consolei, apoi activează opțiunea UPnP (Universal Plug and Play). Pe consolă poți testa și DNS primar 1.1.1.1 / secundar 8.8.8.8 pentru rezolvare rapidă a serverelor.

3. Port Forwarding exact pentru PlayStation Network, Call of Duty și EA FC

Dacă UPnP singur nu trece consola în NAT Type 2, adaugă reguli de Port Forwarding către IP-ul static al PS5/PS4: porturi TCP 80, 443, 3478, 3479, 3480 și 1935; porturi UDP 3478, 3479 și portul esențial UDP 3074 (folosit intens de Call of Duty și matchmaking-ul P2P). După salvare, repornește complet atât routerul, cât și consola (nu doar Rest Mode), apoi rulează Test Internet Connection.

4. De ce rămâne NAT Type 3 chiar și după port forwarding: Double NAT și CGNAT la provider

Există două cauze reale frecvente în Chișinău și Moldova: (a) Double NAT — ai routerul tău Wi-Fi legat în spatele terminalului optic ONT al providerului, ambele făcând NAT; soluția este să ceri trecerea ONT-ului în Bridge Mode; (b) CGNAT (Carrier-Grade NAT) — providerul împarte același IP public la mai mulți abonați. În cazul CGNAT, nicio setare locală din router nu poate deschide porturile; trebuie să soliciți operatorului tău de internet alocarea unei adrese IPv4 publice (dinamică sau statică). Pentru cel mai mic ping și zero packet loss, conectează PS5/PS4 prin cablu Ethernet LAN Cat5e/Cat6 direct din router.

Întrebări frecvente

Trebuie neapărat NAT Type 1 ca să joc fără lag pe PS5?

Nu. NAT Type 2 este exact nivelul optim pentru o conexiune prin router: oferă aceeași compatibilitate completă la matchmaking și voice chat ca NAT Type 1, dar păstrează protecția firewall a routerului tău.

Merită să pun IP-ul PS5 în DMZ pe router?

DMZ poate fi folosit doar ca soluție de rezervă dacă Port Forwarding nu funcționează, dar este obligatoriu ca PS5-ul să aibă IP static (DHCP Reservation) înainte, altfel alt dispozitiv din casă ar putea prelua acel IP.

De ce am ping mare în EA FC / CoD deși am abonament de 500–1000 Mbps?

Viteză mare de download nu înseamnă automat ping mic. Wi-Fi-ul din blocuri aglomerate introduce jitter și pierdere de pachete — un simplu cablu LAN din router în consolă stabilizează imediat ping-ul.
