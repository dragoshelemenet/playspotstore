Pasul 0 (Obligatoriu): pregătirea ambelor console

Conectează-te pe ambele console cu același cont PSN, actualizează firmware-ul la ultima versiune și sincronizează trofeele pe PS4 (Trophies → Options → Sync with PlayStation Network) pentru a nu pierde progresul trofeelor.

Metoda 1: Cablu LAN Ethernet (recomandat pentru tot — profil, jocuri, salvări)

Transferul prin Wi-Fi durează ore întregi pentru câteva sute de GB. Conectează un cablu LAN direct între porturile Ethernet ale PS4 și PS5 (sau ambele la același router). Pe PS5 mergi la Settings → System → System Software → Data Transfer → Continue, apasă 1 secundă butonul Power de pe PS4 până la bip, bifează salvările și jocurile dorite și apasă Start Transfer. Transferul continuă în fundal chiar în timp ce folosești PS5-ul.

Metoda 2: Stick USB FAT32 / exFAT (ideal dacă vinzi PS4-ul înainte să iei PS5)

Pe PS4: Settings → Application Saved Data Management → Saved Data in System Storage → Copy to USB Storage Device → bifezi salvările → Copy. Ulterior, pe PS5: Settings → Saved Data and Game/App Settings → Saved Data (PS4) → USB Drive → Copy to Console Storage. Pentru jocurile pe disc nu ai nevoie să copiezi jocul: introduci discul PS4 direct în PS5 și încarci salvările copiate!

Întrebări frecvente

Pot muta salvările de pe PS4 pe PS5 fără abonament PlayStation Plus?

Da — atât transferul direct prin cablu LAN/Wi-Fi, cât și copierea salvărilor de PS4 pe un stick USB (FAT32 sau exFAT) sunt 100% gratuite și nu necesită PS Plus.

Se șterge ceva de pe PS4 în timpul transferului către PS5?

Nu — datele sunt doar copiate către PS5, iar consola PS4 rămâne intactă până când alegi tu manual să îi dai Factory Reset.
