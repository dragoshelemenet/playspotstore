1. Șterg Clear Cache sau Rebuild Database jocurile și salvările? (Nu!)

Conform documentației oficiale Sony, nici „Clear System Software Cache” (șterge doar fișierele temporare corupte), nici „Rebuild Database” (re-indexează SSD-ul și curăță intrările defecte din baza de date a sistemului) NU îți șterg jocurile instalate, conturile, capturile foto sau salvările. Singurele opțiuni care șterg datele sunt „Reset PS5” și „Reinstall System Software” — pe acelea NU le atinge decât dacă vrei resetare completă din fabrică.

2. Pașii exacți pentru a intra în Safe Mode pe PS5 și PS4

Pasul 1: Oprește complet consola (Turn Off PS5, NU Rest Mode) și așteaptă până se stinge complet LED-ul alb. Pasul 2: Apasă și ține apăsat butonul fizic Power de pe consolă circa 7 secunde până auzi AL DOILEA bip, apoi eliberează-l. Pasul 3: Conectează controllerul DualSense/DualShock 4 cu cablul USB la consolă (Bluetooth este oprit în Safe Mode) și apasă butonul PS. Pasul 4: Alege opțiunea 6 — „Clear Cache and Rebuild Database”, apoi rulează pe rând Clear System Software Cache și Rebuild Database.

3. Ce faci dacă eroarea CE-108255-1 continuă după Rebuild Database

Eroarea CE-108255-1 indică un crash al aplicației/jocului. După curățarea cache-ului: (1) apasă Options pe iconița jocului și selectează „Check for Update”; (2) verifică actualizarea sistemului în Settings → System → System Software → System Software Update and Settings; (3) dacă folosești disc fizic, șterge-l ușor cu o lavetă din microfibră din centru spre margine (niciodată circular), apoi reinstalează jocul curat de pe disc.

Întrebări frecvente

Cât durează Rebuild Database pe PS5?

Datorită SSD-ului rapid NVMe din PS5, operațiunea durează de obicei doar 1–4 minute (pe PS4 cu HDD mecanic poate dura 10–25 minute). Nu scoate consola din priză în timpul procesului.

De ce nu merge controllerul wireless în Safe Mode?

În Safe Mode driverele Bluetooth nu sunt încărcate — ai nevoie obligatoriu de un cablu USB de date (nu cablu simplu doar pentru încărcare) conectat direct la portul USB al consolei.

Cât de des merită să fac Clear Cache / Rebuild Database?

Nu este necesar săptămânal; este util o dată la 3–6 luni după multe instalări/dezinstalări de jocuri mari sau imediat când apar crash-uri CE-108255-1 ori sacadări neobișnuite în meniu.
