PlaySpotStore V38 — Subtle Floating Category Artwork (RO + RU)

What it changes:
- All six homepage category tile images float slowly and independently.
- Hover, text labels, colored borders and clickable category links are unchanged.
- CSS-only: no GIF, extra images or JavaScript; respects Reduce Motion.
- Only index.html, ru.html and new v38 files are touched.
- Works alongside the V34 floating hero, V35 scroll parallax and V37 filters.

Codespaces installation from repo root:
  git pull --ff-only origin main && unzip -o playspotstore-v38-category-float.zip -d . && bash playspot-v38/install.sh

Safe to run again. The installer verifies existing homepage structures and commits
and pushes to main only when changes exist.
